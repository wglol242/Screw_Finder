## 2. 주요 기능

### 1) 이미지 기반 나사 검출
- ONNX 모델을 불러와 입력 이미지에서 나사를 검출하도록 구현
- 검출된 객체의 위치, 신뢰도, 마스크 정보를 기반으로 후처리 수행

### 2) 세그멘테이션 결과 시각화
- 검출된 나사 영역에 색상 오버레이를 적용하고 윤곽선을 함께 표시
- 전체 결과 이미지 위에 격자를 추가해 위치를 직관적으로 확인할 수 있도록 구성

### 3) 리스트 기반 결과 확인
- 검출된 각 나사를 썸네일 이미지와 함께 리스트에 표시
- ID, 중심 좌표(X/Y), 신뢰도를 UI에서 바로 확인 가능

### 4) 선택 나사 상세 확인
- 리스트에서 특정 나사를 선택하면 해당 객체만 강조 표시
- 선택된 나사의 마스크 및 윤곽선을 다시 그려 개별 검출 결과를 확인 가능

### 5) 결과 저장 기능
- 전체 결과 이미지를 저장
- 검출 좌표 및 신뢰도를 CSV 파일로 저장
- 각 나사 이미지를 개별 PNG로 저장
- 최종적으로 ZIP 파일로 묶어 내보내기 지원

## 3. 시스템 아키텍처

- **Vision Engine (C++)**
  - ONNX Runtime을 이용한 모델 로드 및 추론
  - OpenCV 기반 전처리, 후처리, 마스크 생성, NMS 수행

- **Desktop UI (MFC)**
  - 이미지 선택, 실행, 리스트 표시, 선택 객체 강조, 저장 기능 제공

- **Export Module**
  - 결과 이미지 저장
  - CSV 저장
  - 개별 나사 이미지 저장
  - ZIP 압축

## 4. 구현 내용

### 1) ONNX 모델 연동 및 추론 파이프라인
- ONNX Runtime 세션을 생성하고 `best.onnx` 모델을 로드하도록 구현
- 입력 이미지를 640×640 기준으로 letterbox 처리한 뒤 모델 입력 형식에 맞게 변환
- BGR → RGB 변환, 정규화, CHW 변환을 거쳐 추론에 사용

### 2) 검출 결과 후처리
- 모델 출력에서 바운딩 박스, 신뢰도, 클래스 ID, 마스크 계수를 추출
- confidence threshold와 NMS를 적용해 중복 검출을 제거
- 모델 좌표를 원본 이미지 좌표계로 역변환하여 실제 위치 정보 계산

### 3) 마스크 생성 및 시각화
- 프로토타입 마스크와 계수를 조합해 객체별 세그멘테이션 마스크 생성
- threshold를 적용해 이진 마스크를 만들고, 객체 면적과 중심 좌표를 계산
- 결과 이미지에 오버레이, 윤곽선, 격자를 함께 시각화

### 4) MFC 기반 결과 표시 UI
- 이미지 열기 / 실행 / 저장 버튼 기반 워크플로우 구성
- 리스트 컨트롤에 썸네일, ID, X축, Y축, 신뢰도 표시
- 항목 선택 시 해당 나사만 다시 강조해 보여주는 인터랙션 구현

### 5) 결과 저장 기능 구현
- 검출 결과를 `ID, X, Y, Confidence` 형식의 CSV로 저장
- 각 검출 객체를 개별 PNG로 저장
- 전체 결과 이미지와 함께 ZIP 파일로 압축하여 출력

## 7. 프로젝트 요약

Screw Finder는 이미지 속 나사를 자동으로 검출하고,  
각 객체의 **위치, 신뢰도, 세그멘테이션 결과**를 시각적으로 확인할 수 있도록 구현한 Windows 기반 비전 애플리케이션입니다.

단순 검출에 그치지 않고,  
ONNX 모델 추론부터 후처리, MFC UI 구성, 결과 저장 기능까지 직접 구현하여  
실제 검사 보조 도구 형태로 사용할 수 있도록 완성한 프로젝트입니다.
